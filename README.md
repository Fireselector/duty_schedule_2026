# 生产部2026年值班表 (Production Department Duty Schedule 2026)

本仓库包含生产部2026年7月至12月的值班安排，提供iCalendar格式文件方便导入到各种日历应用。

## 项目内容

### 主要文件

1. **值班表.ics** - 完整部门值班表
   - 包含所有员工从2026年7月2日到12月31日的值班安排
   - 每日轮换制，覆盖张浩、蓝洪林、张凌瀚、任晗月、应文忠、王宗宇、吴振榕、刘明钦、白晓龙、魏骥、吕梓杨等员工

2. **我的值班.ics** - 徐迅个人值班表
   - 专门针对"徐迅"的个性化值班安排
   - 包含值班提醒功能（提前26小时和当天8:40提醒）
   - 值班日期：2026年7月1日、7月16日、7月25日等，每半个月左右一次

3. **提示词.md** - 原始生成指令
   - 用于生成值班表的原始指令和人员顺序（日期范围为2026.01.01-2026.06.30）
   - 注：实际生成的iCalendar文件日期为2026.07.02-2026.12.31

### 辅助文件

- **LICENSE** - GNU GPL v2开源许可证
- **.gitignore** - 忽略提示词.md文件

## 注意事项

1. **日期范围差异**：提示词文件指定了2026年1月1日至6月30日的排班需求，但生成的iCalendar文件实际包含2026年7月2日至12月31日的排班。

2. **人员差异**：提示词中包含"陈小星"，但在实际的iCalendar文件中未出现该人员排班。

3. **文件类型**：iCalendar文件采用国际标准格式，兼容绝大多数日历应用。

## 使用方法

### 导入到日历应用

1. **值班表.ics** - 导入到部门共享日历或个人日历查看完整排班
2. **我的值班.ics** - 个人使用，包含提醒功能

#### 支持的应用：
- Google Calendar
- Microsoft Outlook/Teams
- Apple Calendar
- 任何支持iCalendar格式的日历应用

### 文件格式说明

文件采用标准的iCalendar格式（.ics扩展名），包含以下信息：
- 日期时间（北京时区 Asia/Shanghai）
- 值班人员姓名
- 唯一事件标识符
- 徐迅个人值班表包含提醒功能

## 值班周期

值班安排从2026年7月2日开始，到12月31日结束，采用轮换制：
- 每日一人值班
- 节假日和周末正常排班
- 每人值班频率约每周一次

## 技术说明

- 时区：Asia/Shanghai（北京时间）
- 日历格式：iCalendar 2.0
